CASA ALLEGRA — APP WEB INSTALABLE

1) PC (prueba local)
- Doble clic en start_local.bat.
- Se abrirá http://localhost:8080.
- Para detener el servidor, cierre la ventana negra.

2) Publicar para usar desde iPhone
La carpeta completa de esta app puede publicarse en un servicio de alojamiento web estático. Una opción sencilla es Netlify Drop: entrar en https://app.netlify.com/drop y arrastrar la carpeta completa (o el ZIP descomprimido) a la zona de publicación.

3) iPhone / Safari
- Abra la URL publicada en Safari.
- Toque Compartir.
- Seleccione “Agregar a Inicio”.
- Active “Abrir como app web” y toque “Agregar”.

4) Datos
- Los datos se guardan localmente en el navegador/dispositivo.
- Use Configuración > Exportar copia para guardar una copia JSON.
- Use Configuración > Importar copia para restaurarla en otro dispositivo.
- Esta versión NO realiza sincronización automática en la nube entre PC e iPhone.
