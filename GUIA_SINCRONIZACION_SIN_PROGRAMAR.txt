CASA ALLEGRA — guía sencilla para tener los mismos datos en Windows y Safari del iPhone

IMPORTANTE
- La versión Windows abre como programa independiente y puede iniciar sola con Windows.
- La sincronización PC+iPhone necesita una cuenta de nube. Esta versión usa Supabase.
- No hace falta usar CMD para usar CASA ALLEGRA todos los días.
- La clave que se copia a la app debe ser la clave pública ANON. Nunca uses service_role.

PARTE 1 — Crear la nube (una sola vez)
1) Entrá a https://supabase.com/ y creá una cuenta.
2) Creá un proyecto nuevo. Elegí un nombre como CASA ALLEGRA.
3) Esperá a que el proyecto termine de prepararse.
4) Abrí SQL Editor dentro del proyecto.
5) Abrí el archivo SUPABASE_SETUP.sql que viene con esta carpeta y copiá todo su contenido.
6) Pegalo en el SQL Editor y tocá Run.
7) Andá a Authentication / Providers / Email.
8) Para simplificar el inicio de sesión, podés desactivar Confirm email. Así el alta devuelve sesión inmediatamente. Si lo dejás activado, tendrás que confirmar el correo la primera vez.
9) Buscá la configuración de API del proyecto.
10) Copiá la Project URL y la clave pública ANON.

PARTE 2 — Configurar CASA ALLEGRA en Windows
1) Instalá CASA ALLEGRA desde el instalador .exe.
2) Abrí CASA ALLEGRA.
3) Entrá a Configuración.
4) En Sincronización PC + iPhone pegá la Project URL.
5) Pegá la clave pública ANON.
6) Escribí el mismo correo que vas a usar en el iPhone.
7) Elegí una contraseña de al menos 6 caracteres.
8) Tocá Guardar conexión.
9) Tocá Crear cuenta.
10) Si Supabase te pide confirmar el correo, confirmalo.
11) Tocá Iniciar sesión.
12) Tocá Sincronizar ahora.

PARTE 3 — En el iPhone
1) Publicá la carpeta web de CASA ALLEGRA en una dirección HTTPS (por ejemplo Netlify).
2) Abrí esa dirección en Safari.
3) Tocá Compartir → Agregar a Inicio → Agregar.
4) Abrí el ícono CASA ALLEGRA desde la pantalla de inicio.
5) Entrá a Configuración.
6) Usá la misma Project URL, la misma clave pública ANON, el mismo correo y la misma contraseña.
7) Tocá Iniciar sesión.
8) Tocá Sincronizar ahora.

A PARTIR DE AHÍ
- Lo que cambies en la PC se sube automáticamente cuando hay Internet.
- El iPhone trae los cambios cuando la app está abierta y conectada.
- La app también revisa cambios periódicamente mientras está abierta.
- Si dos dispositivos cambian algo al mismo tiempo, gana la versión que tenga la fecha de actualización más reciente.

AUTOINICIO DE WINDOWS
En Configuración → Iniciar con Windows, dejá activada la casilla “Abrir CASA ALLEGRA al iniciar Windows”. No necesitás abrir CMD.

SEGURIDAD
- Usá únicamente la clave pública ANON.
- No compartas la service_role.
- El acceso a los datos queda protegido por RLS para que cada cuenta vea solamente sus propios datos.
