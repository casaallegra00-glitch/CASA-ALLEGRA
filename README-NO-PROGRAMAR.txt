CASA ALLEGRA · versión Windows + sincronización

Para usar la aplicación todos los días no necesitás programación ni CMD.

1. Instalá el archivo CASA-ALLEGRA-Setup-1.1.0-x64.exe.
2. Abrí CASA ALLEGRA desde el acceso directo del Escritorio.
3. Entrá a Configuración y activá “Abrir CASA ALLEGRA al iniciar Windows”.
4. Configurá la nube siguiendo GUIA_SINCRONIZACION_SIN_PROGRAMAR.txt.
5. Usá la misma cuenta en Windows y Safari del iPhone.

NOTA SOBRE EL INSTALADOR
El proyecto está preparado para generar un instalador NSIS de Windows x64 con electron-builder. En este entorno no fue posible descargar los binarios de Electron para generar el .exe final porque la conexión al registro de paquetes no terminó dentro del tiempo disponible. Por eso el ZIP incluye el proyecto completo y la configuración ya preparada.
